## 🚀 Proje Hakkında

**Lumina AI**, klasik ve soğuk yapay zekâ kalıplarını yıkarak gerçek bir insani sıcaklık, üstün analitik akıl yürütme ve çoklu ajan işbirliği sunan eksiksiz bir yapay zekâ ekosistemidir.

Tasarımı **her ekrana sığacak (edge-to-edge, sıfır boş alan)**, akıcı, modern ve tüm cihazlara (mobil, tablet, masaüstü, ultra-geniş ekran) kusursuz uyum sağlayacak şekilde dizayn edilmiştir.

## ✨ Öne Çıkan Özellikler

### 1. 💖 Duygu ve Düşünceleri Hissettiren İletişim
- Robotik klişelerden arındırılmış, kullanıcının ruh halini (sevinç, yorgunluk, stres, merak) sezen ve samimi bir insani sıcaklıkla konuşan yeni nesil persona.
- Empatik, dürüst ve esprili sohbet akışı.

### 2. 📐 Adım Adım Matematik & Bilim Çözücü
- En zor matematik, diferansiyel ve mantık problemlerini:
  - **Problem Analizi & Verilenler**
  - **Kullanılacak Formül & Teoremler**
  - **Adım Adım İşlem (Ara Sağlamalı)**
  - **Nihai Cevap ve Doğrulama**
  şeklinde çözer.
- Formüller **KaTeX** motoru ile ders kitabı kalitesinde matematiksel tipografiyle render edilir.

### 3. 💻 Çoklu Ajan Yazılım Ekibi (Multi-Agent Team)
- Karmaşık yazılım projelerini tek başına değil, 3 uzman ajanın işbirliğiyle hayata geçirir:
  1. **Yazılım Mimarı (Architect):** Sistem mimarisini, klasör ağacını ve teknoloji yığınını belirler.
  2. **Kıdemli Geliştirici (Lead Full-Stack):** Eksiksiz, çalışan ve modüler kod bloklarını yazar.
  3. **Güvenlik & QA Uzmanı (Auditor):** Kodu güvenlik açıkları (XSS, SQLi, bellek sızıntıları) ve edge caseler açısından denetler.

### 4. 🎨 Kusursuza Yakın Görsel Stüdyosu
- **AI Prompt Enhancer:** Türkçe yazdığınız kısa bir fikri, Flux modelinin en yüksek kalitede anlayacağı 8K, 35mm lens, sinematik ışıklandırmalı İngilizce master prompta dönüştürür.
- **Stil Seçenekleri:** 📸 Foto-Gerçekçi, 🎬 Sinematik, 👾 Anime / Manga, 🧊 3D Render, 🎨 Dijital Sanat.
- **En-Boy Oranları:** 1:1 (Kare), 16:9 (Yatay Manzara), 9:16 (Dikey Story / Portre).
- Tek tıkla tam ekran büyütme (lightbox) ve doğrudan cihaza indirme.

### 5. 🌐 Canlı Bilgi & Web Araştırma
- Tavily ve ücretsiz DuckDuckGo canlı arama entegrasyonu ile haberler, borsa, döviz veya güncel olaylar anında taranır ve kaynaklı olarak sunulur.

### 6. 🛡️ Sıfır Hata Dayanıklılığı (Near-Zero Errors)
- **Model Kaskadı (Cascade):** Bir model yoğun veya kotalı olduğunda sistem durmaz; otomatik olarak yedek modellere kesintisiz geçer.
- **Firebase Graceful Fallback:** Firebase anahtarı olmasa bile sistem çökmez; otomatik Yerel Hafıza & Misafir Modu ile %100 çalışır.

### 7.5 🧠 Kalıcı Hafıza
- Kısa vadeli (son mesajlar) ve **kalıcı** (isim, meslek, tercihler vb.) olmak üzere iki katmanlı hafıza.
- Konuşma çok uzasa bile, örneğin başta söylediğin adın unutulmaz.
- Her misafir tarayıcıya özel, birbirine karışmayan kalıcı kimlik.
- Ayarlar menüsünden hafızayı görüntüleme ve tek tıkla sıfırlama.

### 7.6 🔔 Bildirim, Arka Plan & Kendiliğinden Yazma
- Ayarlar'dan açılıp kapanan **kendiliğinden yazma** (sen yazmazken Lumina seni yoklayabilir).
- Soru sorduktan sonra uygulamayı arka plana alsan da işlem sunucuda devam eder; cevap/görsel hazır olunca **bildirim** gelir.

### 7. ⛔ Tavizsiz Güvenlik Kalkanı
- +18 cinsel içerik, şiddet, katliam, tehdit ve yasa dışı talepler tavizsiz ve sert bir dille engellenir.

## 🖥️ Her Ekrana Sığan (Edge-to-Edge) Arayüz

- **Sıfır Boş Alan:** Ekranın tüm piksellerini verimli kullanan, kenar boşluksuz (fluid 100vw x 100vh) modern arayüz.
- **Çoklu Sohbet Geçmişi:** Sol çekmecede geçmiş konuşmalar listelenir, yeni sohbet açılabilir veya silinebilir.
- **Erişilebilirlik & Konfor:**
  - 🌓 Tema Desteği: OLED Siyahı, Gece Mavisi ve Açık Tema.
  - A- / A+ Yazı boyutu ayarlayıcı.
  - 🎤 Sesli Giriş (Speech-to-Text) ve 🔊 Sesli Okuma (Text-to-Speech).
  - 📥 Sohbeti tek tıkla Markdown (`.md`) formatında indirme.

## ⚡ Hızlı Başlangıç (Yerel Bilgisayarda)

### 1. Depoyu Klonlayın
```bash
git clone https://github.com/KULLANICI_ADINIZ/Lumina-AI.git
cd Lumina-AI
```

### 2. Bağımlılıkları Yükleyin
```bash
pip install -r requirements.txt
```

### 3. Çevre Değişkenlerini Ayarlayın
`.env.example` dosyasını kopyalayarak `.env` oluşturun ve Groq API anahtarınızı girin:
```env
GROQ_API_KEY=
```

### 4. Tek Tıkla Başlatın
- Windows kullanıyorsanız **`baslat.bat`** dosyasına çift tıklayın.
- Veya terminalden:
```bash
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```
Tarayıcınızda `index.html` dosyasını açın.

## 🌐 GitHub Pages ile Web Sitesi Olarak Yayınlama

Bu repo **GitHub Pages** üzerinde statik bir web uygulaması olarak doğrudan yayınlanabilir!

1. GitHub'da reponuzun **Settings** > **Pages** bölümüne gidin.
2. **Branch:** `main` / **Folder:** `/ (root)` seçin ve **Save** butonuna tıklayın.
3. Birkaç saniye sonra siteniz `https://kullanici_adiniz.github.io/Lumina-AI` adresinde canlıya geçer.

### Sunucusuz / GitHub Pages Kullanımı:
- Ziyaretçiler sol alttaki ⚙️ **Ayarlar** butonuna tıklayarak kendi **Groq API Anahtarını** girebilir ve hiçbir Python sunucusu olmadan doğrudan tarayıcı üzerinden Lumina AI'ı kullanabilir!
- Kendi backend'inizi Render, Railway veya Vercel'e dağıttıysanız API adresinizi de aynı menüden tanımlayabilirsiniz.
